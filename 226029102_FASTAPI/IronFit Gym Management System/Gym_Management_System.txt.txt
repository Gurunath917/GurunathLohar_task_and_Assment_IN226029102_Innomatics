🏋️ IronFit Gym Management System
🚀 FastAPI Backend Project
📌 Project Overview

IronFit Gym Management System is a backend API built using FastAPI to efficiently manage gym operations such as membership plans, enrollments, and class bookings.

This project was developed as part of internship training at Innomatics Research Labs, focusing on real-world backend development concepts like API design, validation, workflows, and advanced querying.

✨ Key Features
🧾 Plan Management
View all gym plans
Get plan details by ID
Add new plans with validation
Update plan details dynamically
Delete plans with business rule checks
Plan summary insights (cheapest, expensive, features)
👤 Membership Management
Enroll new members
Auto fee calculation with discounts
Referral-based discount system
View all memberships
Search, sort, and paginate memberships
Freeze and reactivate memberships
🧘 Class Booking System
Book gym classes
Validate membership eligibility
View all bookings
Cancel bookings easily
🔍 Advanced API Features
🔎 Search (case-insensitive, smart keywords)
🔃 Sorting (price, duration, name)
📄 Pagination (page & limit)
🎯 Filtering (price, duration, trainer, classes)
⚡ Combined Browse API (search + filter + sort + pagination)
🛠 Tech Stack
🐍 Python
⚡ FastAPI
📦 Pydantic (Data validation)
🚀 Uvicorn (ASGI server)
▶️ How to Run
